# AI-Based Cyberattack Detection System

A college mini-project demonstrating network-flow classification with machine learning and a Streamlit dashboard.

## Features

- Binary classification: Normal (0) vs Attack (1)
- Data preprocessing using scikit-learn pipelines
- Logistic Regression and Random Forest comparison
- Accuracy, precision, recall, F1-score, ROC-AUC and confusion matrices
- Streamlit dashboard with CSV upload, predictions, charts and CSV export
- Model performance page and feature-importance support (when generated)

## Requirements

- Windows 10/11
- Python 3.10 or 3.11 recommended
- VS Code with Python extension
- Internet connection to download the dataset and install Python packages

## Quick start (Windows)

1. Extract the ZIP.
2. Open the extracted `AI_Cyberattack_Detection` folder in VS Code.
3. Download the UNSW-NB15 dataset from:
   https://research.unsw.edu.au/projects/unsw-nb15-dataset
4. Put these two files inside the project's `data` folder:
   - `UNSW_NB15_training-set.csv`
   - `UNSW_NB15_testing-set.csv`
5. Double-click `setup_and_run.bat`, or run it from the VS Code terminal.
6. The script creates a virtual environment, installs dependencies, trains the models, and starts Streamlit.

If PowerShell blocks activation scripts, the batch file uses the venv's Python directly and does not need activation.

## Manual setup

In the VS Code terminal (PowerShell):

```powershell
py -3.10 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe train.py
.\.venv\Scripts\python.exe -m streamlit run app.py
```

If `py -3.10` is unavailable, use `py -3.11` or `python` for the venv command.

## How to use

- **Overview:** project summary and model metric comparison.
- **Traffic Prediction:** upload a CSV containing network-flow features. For UNSW-NB15, the `label`, `attack_cat`, and `id` fields are ignored as model inputs. If labels are present, the app can optionally show evaluation metrics.
- **Model Performance:** compare models and inspect confusion matrices.
- **About:** dataset, algorithms, and limitations.

## Dataset format

This project targets the official UNSW-NB15 training/testing CSV format with a binary `label` column. If you use a different dataset version, verify its column names and target encoding before training.

## Important notes

- The ZIP intentionally does not include the full dataset; it is large and should be downloaded from the official research source.
- The first training run can take several minutes depending on your PC.
- This is a batch-analysis educational prototype, not a live packet capture system.
- Do not interpret dataset benchmark performance as proof that it will detect current attacks in real networks.
- Do not use data you are not authorized to analyze.
- Only load model files you created or trust; `joblib` model files can execute code during loading.
